\section{Research Profile}
Machine learning researcher developing efficient optimization and compression methods for large language models. My work spans pruning, quantization, sparse fine-tuning, pipeline parallelism, and distributed optimization, with an emphasis on methods that connect rigorous analysis to practical open-source systems.
